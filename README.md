
# 🚀 AI Resume Screener

AI-powered Resume Screening Web App using Python and Gradio.

## ✨ Features

- PDF Resume Upload
- Skill Extraction
- Resume Match Score
- Missing Skills Detection
- NLP + Machine Learning
- Modern UI

## 🛠 Tech Stack

- Python
- Gradio
- PyPDF2
- Scikit-learn
- Pandas

## ▶️ Run

```bash
pip install -r requirements.txt
python app.py
