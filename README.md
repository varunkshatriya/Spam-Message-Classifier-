# 🚀 AI Resume Screener

An AI-powered Resume Screening Web Application built using Python, Gradio, NLP, and Machine Learning.

---

# ✨ Features

✅ Upload PDF Resume  
✅ Extract Resume Text  
✅ Detect Resume Skills  
✅ Match Resume with Job Role  
✅ Show Missing Skills  
✅ Generate Resume Match Score  
✅ Resume Summary  
✅ AI Suggestions for Improvement  
✅ Modern UI using Gradio

# ▶️ Installation

## Clone Repository

```bash
git clone https://github.com/varunkshatriya/AI-Resume-Screener.git
```

## Move into Project Folder

```bash
cd AI-Resume-Screener
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

```bash
python app.py
```
